# Instrucciones del proyecto

Lee `AGENTS.md` antes de modificar el proyecto.

La prioridad es una aplicación de escritorio local para limpieza de voz de podcasts. Todo cambio debe preservar los archivos originales y mostrar errores comprensibles para personas no técnicas.

Consulta `docs/current-state.md` para conocer el estado real y `docs/architecture.md` antes de cambiar componentes estructurales. El flujo principal no usa base de datos; toda la lógica vive en `audio-platform/backend/app/api/routes.py`.
